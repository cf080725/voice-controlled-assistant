# 数据安全说明（2026-10-08，10-12 补充）

## 〇、2026-10-12 补充：本机接口、外部客户端与监听

10-08 之后新增了本机接口、MCP、飞书、AutoClaw、聊天语音转写，补充如下（下面一至四节是 10-08 的原文）。

| 项目 | 现状 |
|---|---|
| 团团接口 8789 | 只监听 127.0.0.1，校验 Host / Origin，要求令牌 |
| Muse API 8787、Dots API 4311、Dots 网页 5173 | 代码和启动参数都只监听 127.0.0.1 |
| Muse 网页工作台 8081（Expo 开发服务器） | Expo 默认监听所有网卡（同一 WiFi 可访问）。团团拉起时用 `tools/node_localhost_only.cjs` 预加载，强制只监听 127.0.0.1；绕开团团手动启动 Muse 时不受保护 |
| 主人令牌 | 每次启动在内存里生成，不写盘；只给本机看板 |
| 外部客户端（AutoClaw、MCP 等） | 单独配对、单独撤销，`data/api_clients.json` 只存哈希；默认只能看状态、提出任务；拿不到确认执行、授权训练、改设置；读消息、语音转写、知识库、总结都要主人选定范围 |
| 旧 `data/integration_token.txt` | 降级为只能看状态，要读资料须重新配对 |
| 聊天语音 | 本机 SenseVoice / Whisper 转写；音频临时缓存 30 分钟；只有主人逐条勾选的才用于训练 |
| AutoClaw 云模型 | 它通过 MCP 拿到的任何内容都会进入云端模型上下文，所以默认不给读取权限 |

限制：同一台电脑上以你的账号运行的程序都能读 `data/`，令牌分级防的是接进来的客户端越权，防不了本机恶意程序。

本机还在监听所有网卡的非团团程序（10-12 检查时）：GameViewerServer（远程控制）、GlideXService（华硕投屏）、系统服务；另有 sing-box / v2rayN 代理客户端。没发现 frp、ngrok、cloudflared、tailscale 这类内网穿透。远程控制类软件不用时建议关闭。

原则：**数据安全第一**。能在本机做的不上云；要上云的必须主人明确打开开关；密钥不写在代码里；私人数据不入 git。

### 2026-10-13 深度审查补充

- 桌宠不再自动启动 Dots 双向记忆同步；桥接默认关闭。保存到 Dots、协作任务和下发云端内容必须先确认，“打开网页”等子串不能免除上传确认。
- 系统通知默认只保存和显示通用状态标题，不包含任务标题、提醒正文或消息内容。只有主人明确设置通知 `show_preview: true` 才显示脱敏预览；正则脱敏不能保证去掉人名和敏感语义。旧通知队列不会因修改代码自动清除。
- 无痕开关保存在记忆数据库，API 与主程序共享，跨重启保留。它控制新增记忆和对话日志，不代表停止所有任务审计、截图、插件记录或清除已有数据。
- 记忆页删除移除当前事实/摘要及检索索引。删除、编辑或切换无痕会推进数据库里的记忆版本：旧会话缓冲、正在整理的模型结果、已观察到的后台任务不再写回；慢回复结束时的短期上下文与对话日志也校验版本，重启只恢复最后一次隐私变更之后的对话。
- 新任务摘要附带稳定的来源编号；删除后保留编号阻止同源任务重复导入（即使标题改变）。Dots 导入经过同一写入闸门，传出每条前检查无痕和版本；已经开始的网络请求、已有外部副本不会因此撤回。旧摘要没有来源编号，不能自动推导完整的数据血缘。
- 单条删除不是全盘遗忘：其他已存在的摘要、原始对话日志、全文索引残留、备份和已同步副本仍需独立处理。SQLite 普通表启用 `secure_delete`，但不承诺物理不可恢复；新一轮用户主动输入仍可被记住。
- 外部客户端从两个总结入口提出的请求都等待主人确认；通用任务入口也检查总结来源。知识查询只能使用按文档授权的专用接口。智能体结果权限绑定成功提交的提供商和任务 ID，不能根据正文中的字符串认领任务。
- 公开版导出不读取私人联系人文件，也不删除旧导出目录的 Git 历史或本地修改；更新请输出到新的空目录。扫描是辅助检查，不能证明素材授权齐全或不存在隐私信息。

## 一、只在本机的数据

| 数据 | 位置 | 说明 |
|---|---|---|
| 长期记忆、对话日志、伴侣数值、提醒 | `data/` | 整个目录在 `.gitignore` 里 |
| 密钥 | `data/secrets.json` 或环境变量 `CANAAN_<名字>` | 代码里不写任何密钥 |
| 聊天软件解密导出的聊天记录 | `message_tools/chatapp_tool/local_export/` | **明文**，不入库；建议定期删除旧导出，或开启 BitLocker 磁盘加密 |
| 聊天软件 导出、看板数据、飞书配置 | `message_tools/imapp_tool/**` | 个人配置和数据文件不入库 |
| 语音识别、意图判断、陪聊、语音合成、记忆检索 | 本机模型 | 不联网 |
| 桌面伴侣的桌面感知 | 内存 | 只读窗口标题和进程名，用完即丢，不存不传 |
