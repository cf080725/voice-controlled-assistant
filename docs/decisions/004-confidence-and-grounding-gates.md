# 004 用“先问一句”代替“直接执行”压错误执行（2026-10-07）

## 背景
意图模型 v2 在第二套留出集 fresh（138 条）上仍有 6 次错误执行（目标 ≤3）。要求：改进只能依据调参集（dev / dev2 / unseen，以及新写的探针集 dev3）和新分析，不能看 fresh；最终数字用一套全新的留出集。

## 做法
1. **先冻结新留出集 holdout3（159 条）**，在任何改动之前提交（b89d99b）。它与所有已有评测集和训练数据按字符 3-gram Jaccard < 0.5 去重，集内同一种说法只留一条。之后的改动没有看过它的错例。
2. **动作置信度门槛**：紧凑意图模型输出 `{"a","p"}` 时向 Ollama 要 logprobs，取动作名各 token 概率之积。低于 0.6 就不执行，改成先问一句（原决策放进 `_pending`，用户说“好”再执行）。
   - 阈值只在 dev+dev2+unseen 上定：这几套里一共 4 次错误执行，阈值 0.6 拦下其中 3 次，代价是另有 3 条本来能做对的也要先问一句。阈值再高拦不到更多错误，只会多问。
3. **参数要有依据**（open_app / close_app / open_url / open_path）：参数要么直接出现在原话里，要么能经别名表对上（应用别名、关程序映射、网站名、常用俗称）。对不上就先问“你是说 X 吗？”。
   - 发现过程：dev3 里“把它打开”“那个软件开一下”会被补成 Edge 浏览器。
   - 误拦率：在训练数据 914 条带这类参数的句子里约 4.5%（主要是 ASR 错字，如 tray→trae、“边子”→Edge）。误拦的结果也只是多问一句，不会拒绝执行。
4. **几类句子改为不执行**：
   - 问做法：“电脑怎么截长图”。
   - 描述现象：“声音怪怪的”。
   - 只有动词没有对象：“关了吧”。
   - 转述别人说的话：主语扩充到同学、兄弟姐妹、家人等。
   这几类都来自 dev3 的错例。
5. 试过但没采用：v1/v2 两个模型意见不一致就先问。在调参集上它一次错误都没拦到，却让 3 条对的也要先问。

## 结果（deployed v2 + 上述门槛；基线为同一模型不加门槛）

| 集合 | 错误执行 基线 → 现在 | 正确率 基线 → 现在 | 先问一句（其中本该直接执行的） |
|---|---|---|---|
| fresh（138） | 6 → **4**（2.9%，95% CI 1.1–7.2%） | 87.7% → 88.4% | 8(4) → 12(6) |
| holdout3（159，最终数字） | 9 → **3**（1.9%，95% CI 0.6–5.4%） | 88.1% → 88.1% | 6(3) → 17(9) |
| unseen（125，调参用） | 4 → 1 | 92.0% → 91.2% | |
| dev（210） | 0 → 0 | 98.6% → 98.1% | |

- 新留出集上达到 ≤3；fresh 上 4 次，**未达到 ≤3**。
- 两套的置信区间都与基线重叠，样本量不足以证明降幅显著。
- 代价：holdout3 上约 5.7%（9/159）的正常指令需要多说一声“好”。
- 延迟：意图模型 P50 约 110ms，要 logprobs 不增加可见耗时。

## 回退
`canaan_config.INTENT_MIN_CONFIDENCE = 0` 关闭置信度门槛。参数依据和不执行规则在 `canaan_intent.apply_command_guard` 里。
