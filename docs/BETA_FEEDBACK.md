# 内测说明与反馈问卷

谢谢你帮忙试用。团团是一个**本地运行**的 Windows 桌面助手：屏幕顶上的灵动岛告诉你“谁做完了、谁在等你、谁失败了”，桌宠陪着你，说一句话她帮你办事。所有数据都在你自己的电脑上。

## 一、你会看到什么

- **灵动岛**（屏幕顶部正中）：在听 / 在想 / 说话；来消息时显示来源和条数；VS Code、编程助手、智能体的进度圆环、完成对勾、失败提醒、“等你处理”卡片。
  - 鼠标停在岛上会展开预览，点一下打开列表；列表里右滑忽略、左滑稍后。
- **桌宠**：来提示时转头看岛、做个小动作、冒一句短气泡（点气泡打开对应应用）。你专心打字或全屏时她不打扰。
- **说话办事**：喊“团团”，再说要做的事。涉及发送、删除、付款这类操作，都会先请你确认。

## 二、隐私说明（请先读）

- 对话、消息、记忆都只存在你自己的电脑上；对话原话默认只保留 14 天。
- 聊天和邮件类提示只显示“来源 + 条数”，不显示正文。
- 灵动岛的毛玻璃效果会在内存里模糊岛下方的一小块屏幕，不保存；看板“设置 → 提示中心”可以关掉。
- 我们收不到你的任何数据。只有你自己导出诊断包并发给我们时，我们才看得到其中的内容。

## 三、遇到问题怎么反馈

1. 打开看板（点灵动岛列表里的“看板”）→ 设置 → **导出诊断包**。
   - 诊断包里只有版本、退出记录、崩溃调用栈、每轮耗时和评测分数；
   - 不含对话、消息、记忆和截图，路径、邮箱、手机号已打码。
   - 发不发由你决定。
2. 简单写一句：当时你在做什么、说了哪句话（可以改写，不用原话）、期望发生什么、实际发生了什么。

## 四、问卷（5 分钟）

**关于你**

1. 你每天同时会用几个 AI 工具（聊天助手、编程助手、智能体……）？
2. 你的电脑：显卡和显存、内存大小；装好用了多久？装的时候卡在哪一步？

**灵动岛与提示**

3. 灵动岛有没有让你少切窗口、少错过“等你确认”？举一个例子。
4. 有没有哪一次提示打扰到你了？当时你在做什么？
5. 你觉得提示太多、刚好，还是太少？希望再接入哪些来源？

**说话办事**

6. 你让她做过的事里，哪一句她没听懂或者做错了？（可以改写）
7. 有没有她不该做却做了的事？（这条最重要，请务必告诉我们）
8. 确认步骤是让你安心，还是觉得烦？

**整体**

9. 用一句话说说，你觉得这个产品是干什么的？
10. 如果明天它不能用了，你会觉得：非常可惜 / 有点可惜 / 无所谓？为什么？
11. 你最希望我们下一步改进什么？
